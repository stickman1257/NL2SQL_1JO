# NL2SQL

협업용 NL2SQL 연구/개발 템플릿 레포입니다. 폴더별 `README.md`에는 해당 위치에 어떤 파일을 넣을지 안내가 들어 있습니다.


## Project Structure

```text
NL2SQL/
├── configs/                  # dataset/model/prompt 설정
├── data/                     # raw/processed/sample/schema 데이터
├── docs/                     # 프로젝트 문서와 회의록
├── experiments/              # baseline, ablation, result 기록
├── notebooks/                # 분석 및 시각화 노트북
├── prompts/                  # 프롬프트 원본과 버전 관리
├── scripts/                  # 실행/전처리/평가 스크립트
├── src/nl2sql_agent/         # NL2SQL 패키지 소스
├── tests/                    # 테스트 코드
└── assets/                   # 발표 자료, 그림, 다이어그램
```

## Folder Guide

각 폴더에는 `README.md`가 들어 있습니다. 새 파일을 추가하기 전에 해당 파일을 열어 폴더 목적을 확인하세요.
